## 🎯 Product Summary

**InvoicePDF Pro** is a full-stack invoice management starter kit built with Next.js 14, Prisma, and NextAuth.js. It generates professional PDF invoices via @react-pdf/renderer with 3 customizable templates (Minimal, Modern, Corporate).

### Key Features
- ✅ 3 Professional PDF Templates
- ✅ Invoice & Client CRUD with dashboard
- ✅ Revenue stats & payment tracking
- ✅ Auto invoice numbering (INV-0001...)
- ✅ Multi-currency (USD/EUR/GBP/JPY/CAD/AUD)
- ✅ Tax & discount calculations
- ✅ Authentication (login/register)
- ✅ Responsive Tailwind CSS design
- ✅ TypeScript — full type safety
- ✅ Prisma + SQLite (swap to PostgreSQL in 2 min)

### Tech Stack
Next.js 14 · React 18 · Prisma + SQLite · NextAuth.js · @react-pdf/renderer · Tailwind CSS · Zod · Lucide Icons · TypeScript
