## 📋 Descrizione

Stop sending quotes in Google Docs.

QuoteKit Pro is a full-stack quote management system built for freelancers and agencies who want to send professional estimates, track them through to close, and know their win rate at a glance.

**How it works:**
1. Add a client (or pick an existing one)
2. Create a quote with line items, tax rate, discount, currency
3. Set a validity date — the system flags expired quotes automatically
4. Send the PDF to your client
5. Track status: Draft → Sent → Accepted / Declined / Expired
6. Watch your conversion rate climb on the dashboard

No monthly fees. No SaaS lock-in. You get the full source code and host it yourself.

**What You Get:**
- ✅ Quote CRUD — Create, edit, delete quotes with line items
- ✅ Status Pipeline — Draft → Sent → Accepted / Declined / Expired
- ✅ PDF Export — Professional template via @react-pdf/renderer
- ✅ Validity Dates — Set expiry dates with auto-expiry awareness
- ✅ Notes & Terms — Per-quote notes and T&C section
- ✅ Multi-Currency — USD, EUR, GBP, JPY, CAD, AUD
- ✅ Tax & Discount — Tax rate + flat discount per quote
- ✅ Client Manager — Full client CRUD with contact details
- ✅ Conversion Dashboard — Win rate, totals, and stats at a glance
- ✅ Authentication — Email/password via NextAuth.js, multi-user ready

**Tech Stack:** Next.js 14 (App Router) · TypeScript · Tailwind CSS · Prisma ORM + SQLite · NextAuth.js · @react-pdf/renderer · Zod validation · Lucide icons
